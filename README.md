# Zeitgeist Radar

Interactive cultural intelligence MVP.

## What is included
- Global + APAC market selector
- Japan, South Korea, Hong Kong, Singapore, Malaysia, Thailand, Vietnam, Taiwan, Indonesia, India, The Philippines, Australia and New Zealand
- Interactive cultural radar
- Lens and time-horizon filters
- Signal stream
- Ask-the-Zeitgeist prototype interaction
- Responsive static-site implementation

## Run locally
Open `index.html` in a browser, or serve the folder with any static web server.

## Deploy
This is a static site and can be deployed directly to Vercel, Netlify, Cloudflare Pages or GitHub Pages.
